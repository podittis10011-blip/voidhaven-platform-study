# VH-00 秋招向：VOIDHAVEN 后端从 0 复现课

- 日期：2026-09-21
- 代码真源：本仓库 `apps/api/`（Spring Boot 4.1.1 / Java 17 / Maven / Flyway V1～V24）
- 定位：1.5–2.5 小时把「项目是怎么搭起来的」讲清楚，并接到秋招会问的 Java/Spring/Maven 八股
- 不做：不改正式产品代码、不手写前端、不新建平行仓库、不逐条复刻 24 个迁移和 21 个 Controller

已有 VH-01～VH-06 是「读现码 + 跑测试 + HTTP 复现」。本课是总路线：按真实工程顺序从空 Maven 项目把 API **分层搭起来**。外围从本仓库整文件复制，核心三链路必须能讲实现。

## 30 秒版本（课前先读一遍，课后必须能自己说）

> VOIDHAVEN 是校园竞赛/资源/招募发现平台。后端是 Spring Boot 4 + Maven + MySQL/Flyway。合作方走草稿→审核→发布；公开端只读 `published_revision`。会话用 Cookie + CSRF，写操作用幂等键和 `If-Match`。单机部署，限流/会话/锁都走 MySQL，不用 Redis。

## 合格标准

做完后你必须能：

1. 画出包结构，并说出每个 Spring starter 在本项目里干什么。
2. 默写四维状态 + 两个修订指针。
3. 讲清公开目录：游标、`pageSize+1`、来源 fail-closed、404 语义。
4. 走通 `create → submit → decide → publish`，以及已发布后再 `revise` 为什么不改线上。
5. 区分 401/403、CSRF 豁免边界、409 vs 429。
6. 闭卷说出 30 秒项目介绍。
